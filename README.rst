Описание
-----------
Менеджер для работы с Minio S3

Установка пакетом
-----------
Для локальной разработки::
    pip install -e packages/minio_manager

Импорт
-----------
Проверка::
    from managers.minio_manager import MinioManager


Удаление
-----------
Удалить пакет::
    pip uninstall minio_manager

Для создания пакета
https://docs.python.org/3.10/distutils/introduction.html#distutils-simple-example
https://docs.python.org/3.10/distutils/sourcedist.html
::
    python setup.py sdist
